### Interpretation

- **likely_covered** — capability is already substantially represented in Registry V1; deep review checks whether the external role adds a missing boundary or control.
- **candidate_gap** — capability is not first-class in Registry V1 and deserves contract-level review.
- **partial_or_needs_review** — adjacent capability whose authority/boundary may change the recommendation.
- **not_prioritized** — inventoried but not currently expected to change the roster.
- **outside_current_scope** — domain-specific to work the Factory does not currently target.

No status is an installation recommendation.
