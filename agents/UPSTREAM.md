# Upstream audit provenance

The V1 registry is original work for the eusouakell Agentic Factory.

It was informed by an audit of the public **msitarzewski/agency-agents** catalog, including roles such as Frontend Developer, AI-Generated Code Security Auditor, Reality Checker, UI Designer, UI Finish-Gate Reviewer, Visual Storyteller, Whimsy Injector, Short-Video Editing Coach, Image Prompt Engineer, Inclusive Visuals Specialist and Agents Orchestrator.

Repository:
https://github.com/msitarzewski/agency-agents

The external catalog is used as a benchmark of capability patterns. Agent definitions in this directory are not copied role files and deliberately change authority boundaries to fit Cereja/Flame and the local Agentic Factory model.

Key differences:
- orchestration is control-plane logic, not a privileged persona;
- Flame remains canonical visual authority;
- semantic/editorial judgment stays separate from deterministic checks;
- write authority is branch/domain-scoped;
- all pilot agents remain disabled by default until real-task validation;
- typography and motion are modeled as first-class capabilities instead of being buried inside generic UI roles.
