# Upstream audit provenance

Registry V2 is original work for the eusouakell Agentic Factory.

It was informed by an audit of the public **msitarzewski/agency-agents** catalog.

Repository:
https://github.com/msitarzewski/agency-agents

## Audit coverage

- 282 README-listed agents inventoried;
- 80 roster-relevant contracts reviewed in depth;
- upstream license recorded as MIT;
- no upstream agent file installed as a local agent.

The external catalog is used as a **capability benchmark**.

Local contracts deliberately change authority boundaries and often collapse upstream personas into:

- control-plane responsibilities;
- Guides;
- Guards;
- Sensors;
- Checks;
- Evals;
- skills;
- human gates.

Examples:
- Agents Orchestrator → control plane;
- Git Workflow Master → repository Guide;
- Minimal Change Engineer → executor Guard;
- Prompt Engineer → Guide + eval infrastructure;
- Experiment Tracker → Sensors/protocol;
- Brand Guardian → canonical brand authority + human gate.
