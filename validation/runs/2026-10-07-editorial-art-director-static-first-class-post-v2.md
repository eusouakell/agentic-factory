## Single dominant visual idea

### A system credential that behaves like a real editorial object

The first-class agent is represented by an oversized physical system credential / access badge, treated as a tactile object with material presence rather than a UI card.

The credential is the evidence-object for the idea: an actor exists because the system can identify it, grant bounded authority, know its state and audit what happened.

## Composition

- Build natively in 4:5.
- Warm neutral editorial field with real/tactile light and shadow.
- One oversized credential occupies the lower-right / central depth plane and is partially cropped by the frame.
- Headline occupies the upper-left / mid field and shares depth with the credential: one controlled overlap/occlusion is allowed only where reading remains immediate.
- Credential metadata uses a compact registration/system language, not four decorative pills.
- One physical detail may imply system access — slot, strap, stamp, punched edge, or registration mark — but do not accumulate props/effects.
- Preserve meaningful quiet space; do not fill the frame because the style system has many available assets.

## Type × image

- typography belongs to the scene;
- headline is the primary editorial voice;
- credential is not a second independent panel;
- small system fields should feel functional and subordinate;
- no generic centered headline plus object below;
- do not reduce text to fit: change composition instead.

## Color and materiality

- warm off-white / paper-neutral field;
- ink as primary text;
- cherry embedded in the credential, strap, stamp or one physical material detail;
- lime only if it has an authorization/status job;
- texture comes from light/material/object, not a global grain effect;
- no purple/blue AI shorthand.
